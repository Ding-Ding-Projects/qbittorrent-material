# Appearance Features

Appearance is split into a persisted application-wide layer and sparse
Workspace overrides. Global values establish the default; group and tab values
override only the properties a user explicitly changes.

## Article

- [Runtime appearance and element editor](runtime-appearance.md)

The editor and its search field use the same accessible Material controls and
bounded regex builder as the rest of the desktop app.
