# Workspace Features

The Workspace is the app-owned collection of persistent plain-text pages. It
combines browser-style tab management, bounded Qt regular expressions, local
Git history, and external-editor launch support.

## Articles

- [Tab management and discovery](tab-management.md)
- [Search and regex builder](search-and-regex.md)
- [Local version history](local-version-history.md)
- [External editor integration](external-editor.md)

The Workspace schema is version 2. It can still read schema 1 data and applies
limits before accepting imported state.
